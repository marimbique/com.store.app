# Entity Overview

## Customer

Represents a customer that places orders.

Attributes:

- id
- name
- email
- city

Example:

```java
@Entity
public class Customer {

    @Id
    @GeneratedValue
    private Long id;

    private String name;

    private String email;

    private String city;
}
```

---

## Product

Represents a product sold by the company.

Attributes:

- id
- sku
- name
- price

Example:

```java
@Entity
public class Product {

    @Id
    @GeneratedValue
    private Long id;

    private String sku;

    private String name;

    private BigDecimal price;
}
```

---

# Use Case 12 - Top Customers

## Requirement

Show customers with highest sales volume.

### JPQL Example

```java
@Query("""
SELECT o.customer,
       SUM(i.quantity * i.unitPrice)
FROM Order o
JOIN OrderItem i
ON i.order = o
GROUP BY o.customer
ORDER BY SUM(i.quantity * i.unitPrice) DESC
""")
```

### Learning Goal

- JPQL
- Aggregation
- GROUP BY

# Use Case 16 - N+1 Problem

## Requirement

Load order details efficiently.

### Bad Example

```java
List<Order> orders =
    repository.findAll();

orders.forEach(order -> {
    order.getCustomer();
    order.getItems();
});
```

### Solution

```java
@EntityGraph
```

or

```java
JOIN FETCH
```

### Learning Goal

Performance optimization.
